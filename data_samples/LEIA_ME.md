# Demonstrações
Execute python tools/gerar_amostras.py para criar seis PNGs e o manifesto.
As imagens são sintéticas, produzidas pelo próprio código, sem terceiros.
Cenas: placa autorizada, desconhecida, padrão antigo, pouca luz, desfoque e ausência de placa.
A autorização fictícia padrão é ABC1D23.
Para testes reais, mantenha fotos autorizadas em uma pasta separada e siga docs/PLANO_DE_TESTES.md.
Nenhuma métrica ou promessa de acerto acompanha estas fixtures.

Há também uma imagem PGM já incluída e seu manifesto_incluido.csv.
Ela usa uma fonte bitmap sintética. O OCR pode falhar nessa fonte e isso deve ser registrado.
Não é necessário gerar as seis PNGs para abrir esse exemplo.
